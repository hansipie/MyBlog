![Aperçu de SmartComments](/images/projets/smartcomments.webp)

SmartComments aide les enseignants à rédiger des appréciations : on renseigne le prénom, les notes, les traits de caractère et les matières, et l'application génère un commentaire personnalisé.

## Technique

- Expo SDK 54 / React Native, TypeScript
- Firebase (auth anonyme, Firestore, Cloud Functions Python)
- Génération via LangChain et Claude
- Achats intégrés pour les crédits
